# Resetting Things

::: lead
LaunchControl offers several very different reset actions. Choose the one that matches what you actually want to clear.
:::

| **Action** | **What it clears** | **What it keeps** |
| --- | --- | --- |
| Reset Floor Plan<br> (Settings → Floor Plans) | Panels, cards, devices, lighting configuration, schedules — the coach configuration. | Wi-Fi, PIN, hotspot password, integrations. Use before starting a new floor plan from scratch. |
| Restart Hub<br> (Settings → System) | Nothing; it is only a reboot. | Everything. |
| Factory Reset<br> (Settings → System) | Everything, including Wi-Fi and passwords. | Nothing. Use when selling the coach or starting completely fresh. |

Factory Reset requires typing RESET to confirm and lists what will be lost. Download a backup first if you may want to restore the current configuration later.
