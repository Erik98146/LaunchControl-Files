# The Touch 8 Display

::: lead
Touch 8 mirrors the dashboard you build on the web: the same panels, cards, names, positions, and theme, with touch control for supported cards. When you change the web dashboard layout, Touch 8 updates to match. It connects to the Hub’s own hotspot and continues to work when the RV router is off.
:::

## Set up a Touch 8

1. **Power the display near the Hub.** A new display looks for a LaunchControl Hub hotspot; with exactly one in range and no hotspot password set, it joins by itself and shows the dashboard — nothing else to do.
2. **If it shows a QR code instead,** scan it with your unlocked phone and join the temporary setup network it offers. That happens when no Hub is in range, more than one is, or the Hub hotspot has a password.
3. **Follow the display setup page.** Pick the Hub and enter the hotspot password if there is one.
4. **Finish.** The display downloads the dashboard and reconnects automatically after future restarts.

## Use the Touch 8

- **Panel tabs —** switch panels just like the web dashboard.
- **Card controls —** toggles, sliders, thermostat controls, lighting scenes, and timers work like their web versions.

Touch 8 is a control surface, not a configuration interface. Device setup, card editing, schedules, scenes, and automations are configured in the web dashboard.

## The Settings screen

The hamburger button at the top right of the Touch 8 opens its Settings screen: firmware version and serial, the Hub link, Wi‑Fi signal, the display's address and memory, screen brightness and sleep settings, and a **Remote** row that mirrors the Hub's LaunchControl Remote state — Off, Connecting, *Waiting to be linked* with the link code, or Online with the plan's remaining days. The display never turns Remote on or off; that is done on the Hub's Settings page or in the portal.

## Choose which devices it uses

The Hub normally chooses the battery, water pump, climate zone, and other controls from your dashboard cards automatically. If the coach has multiple devices that could fill the same role, use Settings → Displays to choose which card each Touch 8 should use. For example, assign the climate card for the room where the display is installed.

## If the Hub changes

If the Hub is reset or its hotspot credentials change, the display can return to its QR setup screen while continuing to retry the previous connection. If the Hub returns with the original credentials, the display rejoins automatically; otherwise pair it again.
