# The Mini Display

::: lead
The Mini is a 1.75-inch round AMOLED touchscreen intended for glanceable status and a small set of frequently used controls. It connects to the Hub’s own hotspot and continues to work when the RV router is off.
:::

## Set up a Mini

1. **Power the display near the Hub.** A new Mini looks for a LaunchControl Hub hotspot; with exactly one in range and no hotspot password set, it joins by itself.
2. **If it shows a QR code instead,** scan it with your unlocked phone and join the temporary setup network it offers. That happens when no Hub is in range, more than one is, or the Hub hotspot has a password.
3. **Follow the display setup page.** Pick the Hub and enter the hotspot password if there is one.
4. **Finish.** The display downloads the dashboard and reconnects automatically after future restarts.

## What it shows

- A status face with essential power, temperature, and device controls. A long press will toggle devices. A longer press will start a device timer.
- A sleep timer page
- A master lighting page
- A climate page with thermostat controls
- A detailed power page
- A vehicle leveling page (long press to calibrate)
- A Settings page
- A night friendly large clock that can be set very dim with essential coach information
- Two buttons for additional quick controls

## Choose which devices it uses

The Hub normally chooses the battery, water pump, climate zone, and other controls from your dashboard cards automatically. If the coach has multiple devices that could fill the same role, use Settings → Displays to choose which card each Mini should use.
